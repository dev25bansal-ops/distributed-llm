## Security

- Workers authenticate to the coordinator with shared cluster keys.
- DHT STORE operations require time-bound HMAC capability tokens.

## Performance

- Speculative decoding with a remote draft model (1.3–2.1× speedups).
- Bulk KV-cache dequantization for long-context generation.
