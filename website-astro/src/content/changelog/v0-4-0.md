## Production readiness

This release closes the gap between "works on my machine" and "runs
unattended". Every security-critical path was adversarially audited; findings
were fixed with regression tests.

### Breaking changes

- Weak JWT secrets now **disable** JWT auth at startup instead of warning.
- Unauthenticated `/admin` routes now return 403 when `DISTLLM_HA_SECRET`
  is unset.

### Migration guide

1. Set a strong `API_KEY` (or `API_KEYS` JSON) before starting.
2. If you relied on the old open admin endpoints, create an admin-scoped key.
3. Re-deploy workers with matching cluster keys.
