# Action Plan 06 — Verification & Testing Strategy

**← [[Exhaustive Audit 2026-08-11]]**


The suite is large but not trustworthy at the gate level. 716 test files / 17,494 test functions / 10,838 collected tests (pytest.ini testpaths=tests) sit behind a red CI: the main test job aborts at 36 live collection errors locally (finding [213], .github/workflows/ci.yml:49) and 79 in a fresh CI env, so the 10k+ test body, the --cov-fail-under=80 gate (ci.yml:49) and the quality-gates coverage ratchet (.github/workflows/quality-gates.yml, scripts/ci/coverage_ratchet.py) never actually run on a PR. Root cause of the collection errors is concrete: ~17 regression_high/security/features tests import symbols that were refactored away or never existed (finding [216]) — e.g. tests/regression_high/test_m3_api_key_argon2.py:16 `from distllm.core.api_key_store import hash_api_key` (no such symbol in src/distllm/core/api_key_store.py), test_c6_pickle_rce.py imports `_cuda_reduction_callables` from distllm.dist.zero_copy, test_m4_cors.py imports `CORSError` from distllm.config._network, tests/core/vectorstore/test_vectorstore.py imports `VectorStore` from distllm.core.vectorstore.base. Second structural problem is the fake-import band-aid: 141 files (including tests/helpers.py and 15 conftests) call bootstrap_fake_packages()/make_fake_package() (tests/_import_helper.py:39-61) and inject a sys.modules stub for distllm, distllm.core, distllm.dist, distllm.backends, distllm.models, distllm.config. Yet tests/scripts/check_real_imports.py proves all 287 core modules import cleanly under real imports (tests/scripts/real_import_baseline.json: 287 ok / 0 broken), so the stubs are now largely obsolete and silently mask real import breakage plus the JSONSchemaConstraint stub (tests/_import_helper.py:209-291) replaces real validation logic during the exact tests that should catch structured-output bugs (findings [44],[97]). Third, coverage is structurally uneven: tests/scripts/check_core_coverage_frontier.json records 72 core modules with ZERO test references, including modules with confirmed High bugs — tree_speculative_decoder (finding [33] off-by-one), hydra_diffusion (finding [98]), voyager_multimodal, neural_partition_optimizer, the whole core/evaluation/* package (9 modules) and dp_inference/* (3 modules) — and the gate (tests/scripts/check_core_coverage_frontier.py) only fails when the zero set GROWS, never on the existing debt. Performance/security/chaos coverage is thin and partly dead: the GPU benchmark regression gate uses `runner.environment` which is not a GitHub context key so the GPU branch is always skipped (finding [214], ci.yml:202), docs/BENCHMARKS.md TTFT/ITL tables are still '—' (finding [226], BENCHMARKS.md:127-135) — the single biggest adoption risk — security has bandit+detect-secrets+pip-audit wired (ci.yml:119-167, .pre-commit-config.yaml) but no semgrep and no fuzz for structured-output masks, and DP has no 'no-guarantee' guard (finding [81], src/distllm/core/dp_inference.py:929). CI matrix covers only py3.10/3.11 (ci.yml:41) while pyproject.toml declares 3.10-3.13; `pip install -e ".[dev,testing]"` (ci.yml:48) references a `testing` extra that does not exist (pyproject.toml optional-dependencies.testing is empty); chaos/load jobs collect the whole tree so they are aborted by the same collection errors (finding [220]).

## Unit testing

Make the unit suite the trustworthy core again, in this order. (1) FIX COLLECTION FIRST: every test file that fails to collect on a real import must either (a) update to the current symbol (grep the target module and fix the import), or (b) be marked @pytest.mark.xfail(reason='symbol refactored, tracked in issue <N>', strict=False) at the module top before any import of the missing symbol (e.g. wrap the `from distllm.core.api_key_store import hash_api_key` in try/except ImportError + pytestmark), or (c) be moved to tests/aspirational/ with a pointer to the audit finding. Validate with `pytest --collect-only -q tests/` returning 0 errors. Target: zero collection errors on py3.10/3.11/3.12/3.13 + windows/ubuntu. (2) REMOVE THE FAKE-IMPORT SHADOW: for the 141 files calling bootstrap_fake_packages()/make_fake_package(), delete the bootstrap call and switch to normal `from distllm.core.X import Y` imports (the real-import baseline proves 287/287 core modules import cleanly). Migration order: start with modules that are pure-logic and have clean real imports today (distllm.core.* already in real_import_baseline.json ok[]), keep the stub only for the handful that still need it, and re-run check_real_imports.py to prove no regression. Replace the JSONSchemaConstraint stub (tests/_import_helper.py:209-291) with the real class so structured-output unit tests test real logic. (3) WRITE THE MISSING UNIT TESTS for the 72 zero-reference core modules, prioritized by confirmed High bugs first: tree_speculative_decoder (off-by-one verifier, finding [33]), hydra_diffusion (finding [98]), voyager_multimodal, neural_partition_optimizer, dp_inference.accounting/mechanisms, core/evaluation/*. Each new test file uses real imports, no fakes. (4) ADD THE ADVERSARIAL TESTS THE AUDIT FOUND MISSING (these are cheap and catch confirmed bugs): structured-output schema-compliance test feeding a real schema and asserting the allowed-token mask never permits '}' before required fields (finding [44], src/distllm/core/structured_output/validator.py:99); multi-digit-number FSM continuation `feed '{"a": 1'` and assert digits are in the allowed set (finding [97], __init__.py:202); AudioPipeline two-utterance re-entry test (finding [96], src/distllm/core/media_pipeline.py:254); request_fingerprinting in-flight dedup returns the first response via the public API without touching _in_flight_results (finding [22], src/distllm/core/request_fingerprinting.py:275); BatchScheduler assert paged_attention_mgr.free_sequence called exactly once on completion (finding [11], batch_scheduler.py:1065); PartitionValidator.what_if_slowdown inflates estimated_time_ms and asserts throughput drops (finding [142]); telemetry.flush() re-entrancy (finding [73]); request_latency elapsed_ms frozen on COMPLETED (finding [74], request_latency.py:29); GPUResourceManager.snapshot used_mb/free_mb not swapped (finding [67]). (5) REWRITE THE ~17 BROKEN regression_high/security/features tests per finding [216] triage; make them the regression anchor for the 46 confirmed must-fix bugs (audit_digest.json verified.mustFix=true). Assert every must-fix: add a regression test to tests/regression_high/ that fails on the old behavior (mirror the pattern of test_m3_api_key_argon2.py which is a correct must-fail-on-buggy test — only its import is broken).
