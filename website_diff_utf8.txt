+                        <div class="faq-answer">

+                        </div>
+                    </div>
+
+                    <div class="faq-item">
+                        <button class="faq-question" aria-expanded="false">

+                        </button>
+                        <div class="faq-answer">
+                            <div class="faq-answer-inner">
+                                There is no hard limit. Performance scales linearly up to about 16 GPUs, then communication overhead provides diminishing returns. Most users run 2-8 GPUs effectively.
+                            </div>
+                        </div>
+                    </div>
