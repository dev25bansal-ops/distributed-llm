# Change Log

## 0.4.0 (2026-05-28)

### Features
- Real-time cluster health monitoring in the VS Code status bar
  - Model name with dashboard link
  - Node health (healthy/total)
  - Throughput (tokens/sec) with color coding
- "Send to DistLLM" right-click context menu command
- "Open DistLLM Dashboard" command
- Auto-refresh with configurable interval
- Support for both `/v1/completions` and `/v1/chat/completions` API endpoints
- Configurable settings: API URL, model, refresh interval, max tokens, temperature

### Initial Release
- Basic extension structure with TypeScript source
- ESLint and Prettier configuration
- Extension icon
