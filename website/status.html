No managed service is running
This page is a template, not a live monitor.
Why this page looks like this. DistLLM is free, open source software you run yourself. We do not operate a hosted service, so there is no uptime to report and no status to monitor from our side. This page previously displayed uptime figures and service states that were not measured against anything; we removed them rather than show numbers we cannot stand behind.

Checking your own deployment

If you run DistLLM, you can observe your own cluster rather than relying on this page:

Health endpoints

/health, /ready and /live report real state from your own coordinator.

Metrics

/metrics exposes Prometheus counters you can scrape and alert on yourself.

CLI

distllm cluster status prints the live node list and model state for your pool.

Incidents that affect you

Reported on GitHub

Since distribution and operation are yours, regressions are tracked in the repository's issue tracker rather than here. That is the honest source of truth for what is broken and what was fixed.

Open issues: github.com/dev25bansal-ops/distributed-llm/issues
