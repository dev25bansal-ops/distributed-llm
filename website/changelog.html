Changelog

Release notes, breaking changes, and migration guides for all DistLLM versions.

v0.4.0 2026-05-28 Latest

Production Readiness

Highlights

  • Graceful shutdown with in-flight request draining
  • Structured error responses with error codes and request IDs
  • Kubernetes readiness, liveness, and startup probes
  • Backpressure control with configurable queue depth
  • YAML configuration with environment variable overrides
  • Security hardening: CORS, CSP, SSRF protection, audit logging
  • Health check endpoints: /health, /ready, /live
  • Prometheus metrics and Grafana dashboard templates
v0.3.0 2026-05-14 Breaking

Security & Features

Highlights

  • API key authentication with scoped permissions
  • Rate limiting with token bucket algorithm
  • LoRA adapter hot-swapping
  • Prefix caching for repeated prompts
  • Continuous batching for higher throughput
  • CORS and security headers middleware

Breaking Changes

  • API now requires authentication by default (pass --no-auth to disable)
  • Config file format changed from TOML to YAML
  • Default port changed from 8080 to 8000
Migration Guide

1. Rename config.toml to config.yaml or run distllm config migrate
2. Update port references: 8080 → 8000
3. Generate an API key: distllm auth create-key --name default
4. Pass key in requests: Authorization: Bearer your-key

v0.2.0 2026-04-20

Multi-Node Support

Highlights

  • Multi-node pipeline parallelism across LAN
  • mDNS auto-discovery for worker nodes

  • QR code for easy worker joining
