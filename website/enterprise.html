🔐 Mutual TLS (mTLS)

All node-to-node communication encrypted with client certificate authentication. No shared secrets.

distllm cluster start --mtls --cert /path/to/certs

🔑 RBAC & API Keys

Fine-grained role-based access control. Separate keys for admin, operator, and viewer roles.

distllm auth create-key --role operator --scope "models,cluster"

📝 Audit Logging

Every API call, authentication event, and configuration change logged with immutable audit trail.

distllm config set audit.enabled true --format json

🏰 Air-Gapped Deployment

Full offline installation support. No telemetry, no external dependencies, no internet required.

distllm install --offline --bundle-path /mnt/distllm-bundle.tar.gz
