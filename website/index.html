How It Works

3 commands to distributed inference

Pipeline parallelism — the model is split across devices by layers.

Install & Start

Install with pip and start the coordinator on your main machine.

2

Connect Workers

One command per GPU machine. Workers auto-discover and receive layers.

3

Query the API

Developer Experience

Use from any language

Same API, any SDK. Zero code changes to migrate from OpenAI.

import openai client = openai.OpenAI( base_url="http://localhost:8000/v1", api_key="your-api-key", ) response = client.chat.completions.create( model="meta-llama/Llama-3.2-7B", messages=[{"role": "user", "content": "Hello!"}], stream=True, ) for chunk in response: print(chunk.choices[0].delta.content, end="")
curl http://localhost:8000/v1/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer your-api-key" \ -d '{"model":"meta-llama/Llama-3.2-7B","messages":[{"role":"user","content":"Hello!"}]}'
import OpenAI from "openai"; const client = new OpenAI({ baseURL: "http://localhost:8000/v1", apiKey: "your-api-key", }); const stream = await client.chat.completions.create({ model: "meta-llama/Llama-3.2-7B", messages: [{ role: "user", content: "Hello!" }], stream: true, }); for await (const chunk of stream) { process.stdout.write(chunk.choices[0].delta.content ?? ""); }
from langchain_openai import ChatOpenAI from langchain_core.messages import HumanMessage llm = ChatOpenAI( base_url="http://localhost:8000/v1", api_key="your-api-key", model="meta-llama/Llama-3.2-7B", ) response = llm.invoke([HumanMessage(content="Hello!")]) print(response.content)
