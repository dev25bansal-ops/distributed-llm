How It Works

3 commands to production

Terminal
# 1. Install
pip install distributed-llm
 
# 2. Start coordinator
distllm system api --model Qwen/Qwen2.5-3B --local
 
# 3. Connect worker
distllm cluster join --coordinator 192.168.1.59
 
# 4. Use from any language
curl http://localhost:8000/v1/chat/completions
