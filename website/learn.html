Beginner 10 min

Quick Start: Your First Cluster

Install DistLLM and run your first distributed inference in 10 minutes.

1

Install DistLLM

Terminal
$ pip install distributed-llm
Collecting distributed-llm Downloading distributed_llm-0.4.0-py3-none-any.whl Installing collected packages: distributed-llm Successfully installed distributed-llm-0.4.0
2

Start the Coordinator

Terminal
$ distllm cluster start --model Qwen/Qwen2.5-3B --local --no-auth
[INFO] Starting coordinator on port 50050 [INFO] Loading model Qwen/Qwen2.5-3B... [INFO] Model loaded in 12.3s [INFO] API server running on http://localhost:8000 [INFO] Ready for connections!
3

Test It!

Terminal
$ curl http://localhost:8000/v1/chat/completions \
-H "Content-Type: application/json" \
-d '{"messages":[{"role":"user","content":"Hello!"}]}'
{ "choices": [{ "message": { "role": "assistant", "content": "Hello! How can I help you today?" } }], "usage": {"prompt_tokens": 10, "completion_tokens": 9} }
🎉 Congratulations! You've set up your first DistLLM cluster.

Pipeline Parallelism

How DistLLM splits model layers across GPUs in a pipeline.

How It Works

Pipeline parallelism splits the model into sequential stages, each running on a different GPU. Tokens flow through the pipeline:

  1. Stage 1 (GPU 0): Processes layers 0-7, passes hidden states to next stage
  2. Stage 2 (GPU 1): Processes layers 8-15, continues the pipeline
  3. Stage 3 (GPU 2): Processes layers 16-23
  4. Stage 4 (GPU 3): Processes layers 24-31, produces output token

Advantage: Near-linear scaling. 4 GPUs ≈ 3.5-3.8× speedup.

How It Works

Tensor parallelism splits individual matrix multiplications across GPUs. Each GPU computes a portion of the layer:

  • Column Parallel: Split weight matrix columns across GPUs
  • Row Parallel: Split weight matrix rows across GPUs
  • AllReduce: Combine results after each layer

Best for: GPUs with high-bandwidth interconnect (NVLink, InfiniBand).

How It Works

Sequence parallelism splits the input sequence across GPUs. Each GPU processes a different part of the sequence:

  • Long sequences: Split 8K+ token sequences across 4 GPUs
  • KV Cache: Each GPU maintains KV cache for its sequence portion
  • Communication: Minimal inter-GPU communication required

Best for: Long-context inference (8K-128K tokens).
