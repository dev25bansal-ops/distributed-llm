Methodology

Hardware

All benchmarks run on Ubuntu 22.04, CUDA 12.4, NVIDIA driver 550+. GPUs at stock clocks. 10GbE LAN for multi-node tests.

Workload

Input: 512 tokens, output: 128 tokens. 100 requests with 10 concurrent. Warm-up of 10 requests discarded.

Measurement

tok/s = output tokens / generation time (excludes prefill). Latency = time-to-first-token for streaming. Cost uses electricity at $0.30/kWh.

Reproducibility

Run distllm benchmark run to reproduce. Results in benchmarks/ directory.

Note: Performance varies by driver version, CUDA version, system load, and network conditions. These numbers represent best-case scenarios with optimal configuration. See the benchmark repository for raw data and scripts.
